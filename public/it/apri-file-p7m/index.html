Aprire un file P7M e leggere la fattura elettronica

Trascina qui un file .xml.p7m, .p7m, XML, PDF, ZIP o una PEC. Inviso toglie la busta di firma e mostra la fattura in modo leggibile.

Il file resta sul tuo dispositivo: viene aperto dal browser e non viene caricato su alcun server.

Come funziona

  1. Scegli il file o trascinalo nel riquadro qui sopra.
  2. Inviso estrae il contenuto dalla busta di firma CAdES, anche da archivi ZIP e messaggi PEC.
  3. Leggi la fattura: cedente e cessionario, righe, riepilogo IVA, totali, ritenuta, bollo e dati di pagamento, con il controllo automatico dei totali.

File supportati

  • P7M in DER, Base64 e PEM, anche annidati (.p7m.p7m); P7S, TSD e M7M
  • FatturaPA ordinaria (FPR12, FPA12) e semplificata (FSM10)
  • Notifiche SdI: ricevute di consegna, scarto e mancata consegna
  • PEC con postacert.eml e daticert.xml, e-mail EML e messaggi Outlook MSG
  • Archivi ZIP e ASiC
  • Fatture europee: UBL e Peppol, XRechnung, ZUGFeRD e Factur-X, KSeF, Facturae

Di più con l'app Inviso

L'app per iPhone, iPad, Mac e Android apre i file direttamente da Mail, PEC e File, verifica la firma digitale con la lista di fiducia europea, salva la fattura in PDF e prepara il pacchetto per il commercialista.

L'app per iPhone, iPad, Mac e Android arriva a breve.

Domande frequenti

Cos'è un file P7M?

È un file firmato digitalmente in formato CAdES (PKCS #7). Dentro la busta di firma c'è il documento originale, di solito la fattura XML o un PDF. Le fatture elettroniche firmate dal fornitore arrivano come file .xml.p7m.

Come apro un file .xml.p7m senza programmi?

Trascinalo in questa pagina: il browser lo apre e mostra la fattura in modo leggibile. Non serve installare un software di firma.

Il mio file viene caricato da qualche parte?

No. Il file viene letto dal browser sul tuo dispositivo e non viene inviato a nessun server. La pagina non può trasmetterlo altrove.

La firma digitale viene verificata?

Il visualizzatore web mostra chi ha firmato il file. La verifica della firma, del certificato e della lista di fiducia europea si fa nell'app Inviso.

Posso aprire una PEC con la fattura allegata?

Sì: apri il file .eml della PEC. Inviso mostra il messaggio, i dati di certificazione (daticert.xml) e la fattura allegata.

Posso salvare la fattura in PDF?

Il salvataggio in PDF, la stampa e il pacchetto per il commercialista sono nell'app Inviso. Nel browser puoi visualizzare un file alla volta.
